# AMR Map Editor v0.10.4 — Wall Color Distinction

## Changed
- Wall lines now use an amber/orange color so they are visually distinct from navigation paths.
- Normal wall: `#d97706`.
- Selected wall: `#f97316`.
- Wall endpoint handles and START/END labels use matching orange accents.
- Wall drawing preview uses the wall color instead of the generic blue preview.
- Wall lines use round caps and joins for cleaner connected-wall rendering.

## Unchanged
- Path colors and path direction styles are unchanged.
- Endpoint snapping behavior from v0.10.3 is preserved.
