# Quick Start

1. Open this folder in VS Code.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the editor:
   ```bash
   npm run dev
   ```
4. Run tests:
   ```bash
   npm test
   ```
5. Production build:
   ```bash
   npm run build
   ```

The project uses browser IndexedDB for local project persistence. Large map images are not stored in LocalStorage.
